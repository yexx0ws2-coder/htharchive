# HTH Archive Prototype v5 — Public-safe demo

이 버전은 공개/배포용 더미데이터만 포함합니다.

- 실제 X 계정 핸들 미포함
- 실제 비공개 트윗 URL/상태 ID 미포함
- 실제 배우/배역/작품명/취향 키워드 미포함
- 원본 링크 예시는 `example.com`의 가상 주소만 사용
- 이전 v2~v4 localStorage를 불러오지 않도록 저장 키 분리

# HTH Archive prototype v3

개인 관극 감상 아카이브 프로토타입입니다. `index.html`을 브라우저에서 열면 동작합니다.

## v3 변경사항
- 홈 검색 버튼을 작은 `→` 액션으로 축소
- 작품 상세의 `관극 / 타래 / 배우` 탭과 상단 통계 버튼을 실제 탐색으로 연결
- 작품별 시즌(첫공일–막공일) 옵션 추가
- 같은 작품의 다음 시즌을 별도 카드로 만들 수 있도록 `새 작품` 추가
- HTH↻ 흰 바탕 기본 아이콘을 favicon / 사이드바 / 모바일 헤더에 반영
- 여러 X 계정 저장, 기본 계정 선택, 계정 추가/삭제
- 링크 가져오기에서 URL 작성자 자동 인식 + 내 계정 드롭다운
- 직접 추가에서도 저장한 내 계정 선택
- 메인 카피: `했던 얘기, 또 찾기! / 나만의 관극 감상 외장 드라이브`
- 모바일 상단 액션 버튼 줄바꿈/뭉개짐 수정
- 작품 목록에 작은 수정 펜 버튼 추가
- 작품 수정: 제목 / 시즌 기간 / 배우·배역 / 대표 아이콘
- 기존 이미지 첨부, 검색, 타래 제목 수정, 테마 변경 기능 유지

## 데이터 저장
프로토타입에서는 브라우저 localStorage를 사용합니다. v2 데이터가 있으면 v3에서 가능한 범위로 이어받습니다.

실서비스 단계에서는 X API + Cloudflare Worker/D1 + R2 등의 서버 저장 구조로 교체하는 것을 전제로 합니다.


## v4 캐스트 등록 방식
- 작품 정보에 `배우 · 배역`이 등록되어 있으면 새 관극 화면에서 캐스트를 버튼으로 선택합니다.
- 등록되지 않은 배우도 같은 화면에서 직접 입력할 수 있습니다.
- 작품에 캐스트 풀이 없으면 기존처럼 배우 이름을 직접 입력합니다.
- 같은 작품에서 과거 관극에 `배우 + 배역`을 한 번 저장했다면, 이후 배우 이름만 입력해도 최근 저장된 배역을 자동으로 채웁니다.
- 자동 입력된 배역에는 `자동` 표시가 붙고, 사용자가 언제든 수정할 수 있습니다.
- 작품 정보에 등록된 배역이 있으면 과거 관극 정보보다 작품 정보의 배역을 우선 사용합니다.
